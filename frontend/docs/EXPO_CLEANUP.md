# Expo Cleanup Manifest

Everything listed here is superseded by the Next.js / Express / MongoDB / Capacitor
architecture. The complete original project is preserved in git at commit
`4934d37c10bdb51bd003e0ce2708213dc3953b8c`, so any deletion can be reverted with
`git checkout 4934d37c -- <path>`.

**Totals: 105 files, ~1.39 MB.**

Never deleted: `backend/.env`, `backend/uploads/`, MongoDB data, `frontend/public/`,
`frontend/resources/`, `docs/`, and every workspace package.

---

## Directories

| Path | Files | Why it is removed |
| --- | --- | --- |
| `.expo/` | 4 | Expo/Metro generated cache and router state. Regenerated by Expo tooling only. |
| `app/` | 8 | Expo Router screens. Superseded by `frontend/src/app/(tabs)/*.tsx`. `dev/theme-lab.tsx` and `oauth/callback.tsx` were dev-only/Manus template screens with no runtime behavior in the new app. |
| `assets/` | 10 | Legacy Expo image/font constants. Every file was copied into `frontend/public/` and `frontend/resources/` before removal. |
| `components/` | 9 | Legacy RN components. Superseded by `frontend/src/components/` plus the web primitives in `frontend/src/lib/rn.tsx`. |
| `constants/` | 3 | Expo color/spacing/typography constants. Replaced by Tailwind theme tokens in `frontend/tailwind.config.js`. |
| `hooks/` | 4 | Legacy RN hooks. Ported into `frontend/src/hooks/`. |
| `lib/` | 10 | tRPC client, Manus OAuth, `constants.ts`. Replaced by `frontend/src/lib/api.ts` (Express REST + JWT refresh). |
| `server/` | 20 | tRPC + Express + MySQL/Drizzle backend. Replaced by `backend/` (Express + Mongoose, route-for-route equivalent). |
| `tests/` | 4 | Vitest suites targeting the deleted tRPC/Manus layer. Covered by `backend/tests/` and `shared/types/__tests__`. |
| `drizzle/` | 10 | MySQL schema + client. Database is now MongoDB (`backend/src/models`). A one-off importer is kept at `backend/src/scripts/migrate-mysql.ts`. |
| `dist/` | 1 | Stale Expo production bundle. Unreproducible and superseded by `frontend/out/` and `backend/dist/`. |
| `scripts/` | 3 | `generate_qr.mjs` built `exps://` Expo deep-link QR codes (no deep link exists in the new app); `load-env.js` and `reset-project.js` existed only to boot the Expo app. |

## Root files

| Path | Why it is removed |
| --- | --- |
| `.watchmanconfig` | macOS-only watcher tuning for the old Metro bundler. |
| `app.config.ts` | Expo app config (`expo.audio`, scheme `exps`, plugins). Android config now lives in `frontend/capacitor.config.ts`. |
| `babel.config.js` | Babel presets for the Expo/Metro pipeline. Next.js uses SWC and its own config. |
| `drizzle.config.ts` | Points at MySQL. No relational database remains. |
| `eas.json` | Expo Application Services build profiles (EAS Build / Submit). Android now builds via Gradle. |
| `eslint.config.js` | Extends `eslint-config-expo`. Replaced by `frontend/eslint.config.mjs`. |
| `expo-env.d.ts` | Ambient types for `expo-env.d.ts` / `expo/types`. No Expo packages installed. |
| `global.css` | Imported by the root Expo layout for NativeWind. Tailwind entry point is `frontend/src/app/globals.css`. |
| `legacy-expo-package.json` | Preserved copy of the original manifest, kept for reference during migration. |
| `metro.config.js` | Metro bundler configuration for React Native. |
| `nativewind-env.d.ts` | NativeWind type declarations. NativeWind is gone. |
| `pnpm-lock.expo-original.yaml` | Frozen lockfile of the pre-migration dependency graph. |
| `tailwind.config.js` | NativeWind preset in CommonJS scanning `app/`, `components/`, `lib/`, `hooks/`. Replaced by `frontend/tailwind.config.js`. |
| `template.json` | Manus project template metadata (tags, overview, design system notes). No runtime or build role. |
| `theme.config.d.ts` / `theme.config.js` | Color swatch map consumed only by the removed root Tailwind config. The same values live in `frontend/tailwind.config.js`. |
| `tsconfig.json` | `extends: expo/tsconfig.base` with `nativewind/types` and `.expo/types`. Nothing references it: `frontend/`, `backend/`, and `shared/` each ship a self-contained tsconfig, and `backend/build.mjs` pins `tsconfig.build.json`. This file was also the source of the `Cannot find base config file "expo/tsconfig.base"` build warning. |
| `.env.example` | Expo/Manus/MySQL variables (`EXPO_PUBLIC_*`, `DATABASE_URL=mysql://`, `BUILT_IN_FORGE_API_KEY`). Replaced by `backend/.env.example`. |
| `.gitkeep` | Placeholder for the now-removed root app directory. |
